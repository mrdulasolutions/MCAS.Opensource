## First-run panel (minimum)

**Actives / hypotheses**

1. Sulforaphane  
2. Erucin  
3. Luteolin  
4. Palmitoylethanolamide (PEA)  

**Negative controls**

5. Acetaminophen  
6. Metformin  

**Optional expansion:** Curcumin, Baicalein, PEITC, Midostaurin (positive clinical anchor).

## Terms (non-negotiable)

- **No NDA** for core assay results destined for public EXP reports.  
- **No exclusive IP assignment** to OpenMCAS; partner may publish independently.  
- **Publish either way** — positive *or* negative β-hex results become an EXP report.  
- **CUI / patient PHI never shared.**

## Success for this pack

A partner has:

1. Confirmed cell system (LAD2 or primary human mast cells),  
2. Agreed the preregistered dose grid,  
3. Quoted or scheduled the 6-compound minimum panel.
